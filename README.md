# Registration Form

A responsive registration form built using **HTML, Tailwind CSS, and JavaScript**.

### Features
- Real-time form validation.
- Name and email validation.
- Password validation (minimum 6 characters).
- Live Bio character counter (200 characters).
- Submit button enabled only when all fields are valid.
- Success message after submission.

### Technologies Used
- HTML5
- Tailwind CSS
- JavaScript

### Concepts Practiced
DOM Manipulation, Event Listeners, Form Validation, and Conditional Statements.
